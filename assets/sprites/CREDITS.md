# Pokémon sprites

Front and back sprites for all 16 species were fetched from each Pokémon's
`sprites.front_default` and `sprites.back_default` fields at
https://pokeapi.co/api/v2/pokemon/{name} on September 7, 2026.

Source repository: https://github.com/PokeAPI/sprites
API documentation: https://pokeapi.co/docs/v2#pokemon

Cached locally so the game works offline, following PokéAPI's caching policy.
Pokémon and Pokémon character images belong to their respective owners,
including Nintendo, Creatures, and GAME FREAK. This is an unofficial private fan project.
